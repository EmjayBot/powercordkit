How snowflakes work

63…22 timestamp ms since 2015-01-01 21…17 worker id 16…12 process id 11…0 increment
Discord epoch = 1420070400000 (2015-01-01T00:00:00Z). Created-at = (id >> 22) + epoch. IDs sort by creation time, so a bigger ID is always newer.
